# NetworkLoop Branding

## App icon

The production icon is stored at:

```text
assets/branding/networkloop-icon.png
```

It is a 1024×1024 RGB PNG with no transparency, suitable as the source icon for iOS.

The mark combines an abstract relationship loop, a subtle N-shaped path, and connection nodes. The
palette matches the app interface:

- Deep teal: `#365E5A`
- Forest teal: `#294A47`
- Warm off-white: `#F6F7F9`
- Soft sage accent

The icon was generated with the built-in image-generation workflow using this production brief:

> Create a simple, memorable abstract network-loop symbol: two interlocking curved paths forming a
> subtle letter N and an endless relationship loop, with three small connection nodes integrated
> into the paths. Use a premium flat vector-like style, centered composition, generous safe
> padding, deep muted teal, forest teal, warm off-white, and a restrained sage accent. No text,
> watermark, device mockup, transparent background, or baked-in rounded-corner mask.
